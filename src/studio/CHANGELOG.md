# 变更日志

本项目的所有重要变更都会记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.0-alpha.1] - 2026-10-16

### 新增

- 职位管理系统原型（依据《职位》手册 `docs/tutorial/role/title.md`）：总览 / 职位 / 成员 / 登记四个页面
- 职位槽位：按机构分组的职位档案，职责边界、编制、权能（决策/执行/仲裁）、治理/经营类别、冻结状态
- 任职登记：新任、免任、兼任与主要职位变更，均须登记生效日期与变更依据（变更即登记）
- 主要职位规则：一人一主职——首次任职自动指定、切换时同成员其余任职降级、免任时按治理优先自动接续
- 成员职务清单：按「成员：主要职位、职位、职位」罗列，主要职位列于首位；兼任汇报对象按职位登记
- 推导视图：空缺/超编/冻结与登记缺口在总览聚合，变更登记流水可追溯
- 测试：`position_store_test.dart` 规则单测 9 项 + `widget_test.dart` 页面与登记流程 5 项
